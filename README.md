# Solvoya – Travel Website

Solvoya is a modern and responsive travel website that allows users to explore popular destinations, discover hotels, and plan their next adventures through a clean and user-friendly interface.

## Live Demo

[View Solvoya Website](https://Muhaned-7.github.io/Solvoya/)

## Features

- Modern and clean user interface.
- Fully responsive layout for desktop, tablet, and mobile screens.
- Homepage with a hero section.
- Popular destinations section.
- Featured hotels section.
- Destination search with JavaScript filtering.
- Favorites page to save preferred destinations and hotels.
- Sign In and Sign Up pages (front-end UI only, no backend yet).

## Getting Started

To run this project locally:

1. Clone the repository:

```bash
git clone https://github.com/Muhaned-7/Solvoya.git
cd Solvoya
```

2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension, then right-click `index.html` and choose **Open with Live Server**.
